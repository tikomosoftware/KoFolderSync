# フォルダ同期アプリ

シンプルで使いやすいフォルダ同期アプリケーションです。ソースフォルダから同期先フォルダへファイルを効率的にコピーし、オプションで完全同期（ミラーリング）も可能です。

## 主な機能

### 📂 フォルダ同期
- ソースフォルダから同期先フォルダへファイルをコピー
- 更新されたファイルのみを自動検出してコピー（増分同期）
- マルチコアCPUを活用した並列処理で高速に同期

### 🔄 完全同期（ミラーリング）
- オプション機能：同期先にのみ存在するファイルを削除
- ソースフォルダと完全に一致した状態を維持

### 🎯 ドラッグ&ドロップ対応
- エクスプローラーからフォルダを直接ドラッグ&ドロップするだけで設定完了

### ⏸️ 同期の途中停止
- 「停止」ボタンで同期を安全に中断可能

### 💾 設定の自動保存
- 前回選択したフォルダを自動記憶

## 🚀 インストール・使用方法

### 📦 パッケージ内容
本パッケージは **.NET同梱版** です。
.NET 10.0 ランタイムが含まれているため、追加のインストールは不要です。

### インストール手順
1. ダウンロードしたZIPファイルを解凍
2. `FolderSync.exe`（または実行ファイル）を起動

### 基本的な同期手順
1. **ソースフォルダを選択**: フォルダをドラッグ&ドロップまたは参照ボタンから選択
2. **同期先フォルダを選択**: 同様に選択
3. **同期開始**: 「同期開始」ボタンをクリック

## ⚠️ 重要な注意事項

### 完全同期モードの使用
- このモードでは、同期先の余分なファイルが**削除**されます。実行前に必ず内容を確認してください。

### 同期先フォルダの選択
- システムフォルダや重要なデータが含まれるフォルダは慎重に選択してください。
