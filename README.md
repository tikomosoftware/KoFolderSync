# フォルダ同期アプリ

[![.NET](https://img.shields.io/badge/.NET-10.0-blue.svg)](https://dotnet.microsoft.com/)
[![Platform](https://img.shields.io/badge/Platform-Windows-lightgrey.svg)](https://www.microsoft.com/windows)

シンプルで使いやすいフォルダ同期アプリケーションです。ソースフォルダから同期先フォルダへファイルを効率的にコピーし、オプションで完全同期（ミラーリング）も可能です。

## 主な機能

### 📂 フォルダ同期
- ソースフォルダから同期先フォルダへファイルをコピー
- 更新されたファイルのみを自動検出してコピー（増分同期）
- ファイルサイズと更新日時を比較して最新の状態を維持

### ⚡ 高速並列処理
- マルチコアCPUを活用した並列処理
- 大量のファイルも高速に同期
- CPUコア数に応じて自動最適化（4コアで約3〜3.5倍、8コアで約5〜6倍高速化）

### 🔄 完全同期（ミラーリング）
- オプション機能：同期先にのみ存在するファイルを削除
- ソースフォルダと完全に一致した状態を維持
- 空になったフォルダも自動削除

### 🎯 ドラッグ&ドロップ対応
- エクスプローラーからフォルダを直接ドラッグ
- テキストボックスにドロップするだけで設定完了
- ファイルをドロップした場合は親フォルダを自動設定

### ⏸️ 同期の途中停止
- 「停止」ボタンで同期を安全に中断
- 処理済みのファイル数を確認可能
- 並列処理中でも即座に停止

### 💾 設定の自動保存
- 前回選択したフォルダを自動記憶
- アプリ起動時に前回の設定を復元
- ソースフォルダと同期先フォルダを個別に記憶

### 📊 進捗表示とログ
- リアルタイムの進捗バー表示
- 詳細なログ出力（コピー、スキップ、削除など）
- 処理時間とファイル数の統計表示
- ログのクリア機能

### 🎨 使いやすいUI
- 直感的なインターフェース
- 縦方向にリサイズ可能（ログ領域が拡大）
- 画面中央に起動

## システム要件

- **OS**: Windows 10/11 (64-bit)
- **.NET**: .NET 10.0 ランタイム
- **メモリ**: 最小 100MB
- **ディスク容量**: 最小 10MB
- **推奨**: マルチコアCPU（並列処理の恩恵を受けるため）

## 使い方

### 基本的な同期手順

1. **ソースフォルダを選択**
   - 方法1: 「参照...」ボタンをクリックしてフォルダを選択
   - 方法2: エクスプローラーからフォルダをドラッグ&ドロップ

2. **同期先フォルダを選択**
   - 方法1: 「参照...」ボタンをクリックしてフォルダを選択
   - 方法2: エクスプローラーからフォルダをドラッグ&ドロップ

3. **同期オプションの設定（任意）**
   - 完全同期が必要な場合は「同期先にのみ存在するファイルを削除する（完全同期）」にチェック
   - ⚠️ このオプションを有効にすると、同期先の余分なファイルが削除されます

4. **同期開始**
   - 「同期開始」ボタンをクリック
   - 確認ダイアログで内容を確認後、「はい」をクリック

5. **同期の停止（必要に応じて）**
   - 同期中に「停止」ボタンをクリック
   - 処理が安全に中断され、処理済みの結果が表示されます

### 完全同期（ミラーリング）モード

完全同期モードを使用すると、同期先フォルダがソースフォルダの完全なコピーになります。

**動作:**
- ソースフォルダに存在するファイル → 同期先にコピー
- ソースフォルダに存在しないファイル → 同期先から削除 ⚠️
- 空になったフォルダも自動削除

**使用例:**
- バックアップの完全なミラーを作成
- 開発環境と本番環境のフォルダを一致させる
- 古いファイルを削除しながら同期

### ログの見方

ログには以下の情報が表示されます：

- `並列処理モード: 最大Xスレッド` - 使用するCPUコア数
- `コピー: <ファイルパス>` - 新規またはファイルが更新されたため、コピーされました
- `スキップ (最新): <ファイルパス>` - 既に最新版が存在するため、スキップされました
- `削除: <ファイルパス>` - 完全同期モードで削除されました
- `空フォルダ削除: <フォルダパス>` - 空のフォルダが削除されました
- `処理時間: X.XX秒` - 同期にかかった時間
- `コピー: Xファイル, スキップ: Yファイル` - 処理結果の統計

## 安全性と注意事項

### ⚠️ 重要な注意事項

1. **完全同期モードの使用**
   - このモードでは、同期先の余分なファイルが**削除**されます
   - 実行前に必ず確認ダイアログの内容を確認してください
   - 重要なファイルは事前にバックアップを取ることをお勧めします

2. **同期先フォルダの選択**
   - システムフォルダ（Windows、Program Filesなど）は選択しないでください
   - 重要なデータが含まれるフォルダは慎重に選択してください

3. **実行中の注意**
   - 同期中はファイルを編集しないでください
   - 大量のファイルがある場合、処理に時間がかかることがあります
   - 途中で停止したい場合は「停止」ボタンをクリックしてください

4. **並列処理について**
   - 複数のファイルが同時にコピーされます
   - ネットワークドライブの場合、並列処理が逆に遅くなる可能性があります
   - SSDの場合、並列処理の効果が最大限に発揮されます

### 🛡️ セキュリティ

- ローカルファイルシステムのみにアクセス
- ネットワーク通信は行いません
- 設定ファイル（`FolderSyncSettings.json`）はアプリと同じフォルダに保存されます

## トラブルシューティング

### よくある問題

**Q: 同期が完了しない**
- ファイルが使用中の可能性があります。他のアプリケーションを閉じてください
- アクセス権限を確認してください
- ログを確認してエラーメッセージを確認してください
- 「停止」ボタンで一旦中断し、問題を確認してください

**Q: 「ソースフォルダが存在しません」エラー**
- フォルダが削除または移動された可能性があります
- ネットワークドライブの場合、接続を確認してください

**Q: 一部のファイルがコピーされない**
- ログを確認してエラーメッセージを確認してください
- ファイルのアクセス権限を確認してください
- ファイルが他のプログラムで使用中でないか確認してください

**Q: 完全同期で削除したくないファイルが削除される**
- 完全同期モードではソースに存在しないファイルは全て削除されます
- 必要に応じて、完全同期モードのチェックを外してください

**Q: ネットワークドライブへの同期が遅い**
- ネットワーク速度がボトルネックになっている可能性があります
- 並列処理が逆効果になる場合があります

**Q: ドラッグ&ドロップができない**
- フォルダ（またはファイル）をテキストボックスの上にドロップしてください
- 管理者権限で実行している場合、通常権限のエクスプローラーからはドロップできません

## パフォーマンス

### 並列処理の効果

実際のパフォーマンスはファイルサイズ、ディスクI/O速度、ネットワーク速度に依存しますが、目安として：

- **シングルスレッド**: 1,000ファイル/分
- **4コアCPU**: 3,000〜3,500ファイル/分（約3〜3.5倍）
- **8コアCPU**: 5,000〜6,000ファイル/分（約5〜6倍）

### 最適な使用環境

- ✓ ローカルSSD間のコピー（最速）
- ✓ ローカルHDD間のコピー（高速）
- △ ネットワークドライブへのコピー（ネットワーク速度に依存）
- △ USBドライブへのコピー（USB速度に依存）
